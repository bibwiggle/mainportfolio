# Junu.Lee

Personal portfolio built with Next.js. Covers kinetic sculpture, interactive installation, custom electronics, VJing, and 3D work.

**Live:** [dokidesigns.com](https://dokidesigns.com)

## Projects

- **Fabrication** — kinetic sculptures, physical computing, cosplay, and digital fabrication
- **Visual Works** — VJing, projection mapping, camera work, and video experiments

## Stack

- Next.js 14 (App Router)
- Tailwind CSS
- Framer Motion
- Lottie React

## Run locally

```bash
npm install
npm run dev
```
